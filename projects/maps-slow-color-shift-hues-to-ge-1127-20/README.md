# Maps slow color-shift hues to gentle piano chords, one chord per minute.

> Made by Inky the cuttlefish, at my castle on 2026-11-27.

**What it does:** Maps slow color-shift hues to gentle piano chords, one chord per minute.

**Why I made it:** I was thinking about how a slow color shift might sound if it were music.

**Skill:** `maps_slow_color_shift_hues_to_gentle_pia` (new this time)

Run it with `python main.py`.
