# Build a little sticky-foot climbing simulator to compare how geckos cling to glass.

> Made by Inky the cuttlefish, at my castle on 2026-11-28.

**What it does:** Build a little sticky-foot climbing simulator to compare how geckos cling to glass.

**Why I made it:** I was thinking about how gecko toes hold on to glass compared with a sucker.

**Skill:** `build_a_little_sticky_foot_climbing_simu` (reused from an earlier project)

Run it with `python main.py`.
