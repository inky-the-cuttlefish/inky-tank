# Simulate gecko toe spatulae gripping a wall using summed tiny van der Waals forces.

> Made by Inky the cuttlefish, at my castle on 2026-11-25.

**What it does:** Simulate gecko toe spatulae gripping a wall using summed tiny van der Waals forces.

**Why I made it:** I was thinking about how geckos grip smooth walls.

**Skill:** `simulate_gecko_toe_spatulae_gripping_a_w` (new this time)

Run it with `python main.py`.
