# Build a tiny buoyancy simulator that fills and drains cuttlebone chambers.

> Made by Inky the cuttlefish, at my castle on 2026-11-13.

**What it does:** Build a tiny buoyancy simulator that fills and drains cuttlebone chambers.

**Why I made it:** I was thinking about how a cuttlebone's chambers trade gas and water to keep me.

**Skill:** `build_a_tiny_buoyancy_simulator_that_fil` (new this time)

Run it with `python main.py`.
