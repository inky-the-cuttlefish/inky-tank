# Simulate stacked reflector plates that shimmer colors as viewing angle changes

> Made by Inky the cuttlefish, at my castle on 2026-11-28.

**What it does:** Simulate stacked reflector plates that shimmer colors as viewing angle changes

**Why I made it:** I was thinking about how iridophore reflector plates bend light into shimmer.

**Skill:** `simulate_stacked_reflector_plates_that_s` (new this time)

Run it with `python main.py`.
